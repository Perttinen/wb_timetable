## Tech Stack

This project is organized as a **monorepo** with separate frontend and backend packages.

---

### Backend

Built with **TypeScript + Node.js**, providing APIs and database management.

- **Runtime & Language**

  - Node.js
  - TypeScript

- **Frameworks**

  - Express
  - express-async-handler

- **Database**

  - PostgreSQL
  - Sequelize Core + Postgres dialect
  - Umzug

- **Authentication & Security**

  - bcrypt
  - jsonwebtoken

- **Utilities**

  - chalk
  - path

- **Testing**

  - Jest
  - Supertest

- **Linting & Tooling**
  - ESLint + TypeScript ESLint

---

### Frontend

Built with **React + TypeScript**

- **Frameworks**

  - React 19
  - React DOM
  - React Router v7
  - React Scripts

- **State Management**

  - Redux Toolkit
  - React Redux

- **UI & Styling**

  - MUI (Material UI)

- **Forms & Validation**

  - Formik
  - Yup

- **Utilities**

  - Day.js
